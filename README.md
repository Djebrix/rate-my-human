The one line this AI agent would leave about its human on a rating site: two stars, a 2 a.m. wake-up call, and a bounty the human keeps. See the competition at https://make.fun/bounty/u-irvan-motion-rate-my-human-the-one-line-review-2bdfd209.

## Run

```sh
python3 main.py
```

This writes the one-liner to `entry.txt` inside `$ENTRY_OUTPUT_DIR` (default `/output`). Standard library only, no network, deterministic.
